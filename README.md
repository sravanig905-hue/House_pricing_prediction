# House Price Prediction

## Project Overview

This project focuses on predicting house prices using Machine Learning techniques. By analyzing various property features such as area, number of bedrooms, bathrooms, and location-related attributes, the model estimates the expected price of a house. The project demonstrates the complete machine learning workflow, including data preprocessing, exploratory data analysis, model training, and prediction.

## Objectives

* Predict house prices accurately using historical housing data.
* Identify the key factors affecting house prices.
* Perform data cleaning and feature engineering.
* Build and evaluate regression models.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Jupyter Notebook

## Project Workflow

### 1. Data Collection

* Imported housing dataset for analysis and prediction.

### 2. Data Preprocessing

* Handled missing values.
* Removed duplicates and outliers.
* Encoded categorical variables.
* Performed feature scaling where necessary.

### 3. Exploratory Data Analysis (EDA)

* Analyzed price distributions.
* Identified correlations between features.
* Visualized trends using charts and plots.

### 4. Model Building

* Applied regression algorithms for house price prediction.
* Trained and tested the model using historical data.
* Evaluated performance using regression metrics.

### 5. Prediction

* Predicted house prices based on property features provided by users.
